设计要点

  1. 只有一个会动的东西。实时行出现后，工具组行回到静态的叠层图标，不再同时转圈。
  2. 左侧 Mark 描边。图标沿 Eidos 切角方块的轮廓走一圈亮线，强调色 --accent，15px。
  3. 一行、不换行。文字沿用工具组运行态的 shimmer，超出省略。没有计时（上方“正在处理 Ns”已有）。
  4. 有内容才可点。有思考摘要时整行是按钮，点击在上方弹出气泡，不推动 Feed；没有摘要时它只是状态，不是按钮。
  5. run 结束即消失。不留历史，不写入 SQLite。
