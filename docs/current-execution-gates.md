# 执行门控清单

本文列出基于 main 的整体整改决策。移除只约束调用形式、输入编辑或无关任务的门控；不能证明结果、授权、版本或所有权的操作继续受约束。检查尽量由 Runtime 处理，不把内部恢复步骤强加给模型或用户。

## 输入与审批

| 编号 | 检查或门控 | 决策 | 当前行为与依据 |
|---|---|---|---|
| 1 | “下一步必须先只读核验” | 移除 | Runtime 自动恢复可核验 Workspace Intent；不要求模型先读取文件。 |
| 2 | 未使用的 `CONTINUE_READ_ONLY` 分类与返回字段 | 移除 | 状态权威是持久 Intent 和 reconciliation；删除无消费者的分类器。 |
| 3 | Feed 强制引导“等待只读核验” | 移除 | 展示操作冲突或结果尚未确认的实际事实。 |
| 4 | 模型加载或未配置时禁用草稿编辑 | 调整 | 可编辑已载入草稿；执行提交仍需有效模型。 |
| 5 | 收尾、待审批或工作区不可执行时禁用编辑 | 调整 | 普通 Composer 显示时保留草稿编辑；审批和澄清期间由专用交互替换普通 Composer。 |
| 6 | 审批卡片替换普通输入框 | 恢复 | 待审批时由 ApprovalComposer 占据 ComposerSlot，普通输入框暂时隐藏。 |
| 7 | 澄清卡片替换普通输入框 | 恢复 | 等待回答时由 ClarificationComposer 或状态提示占据 ComposerSlot。 |
| 8 | 草稿未加载、正在提交时编辑限制 | 保留 | 防止覆盖持久草稿或正在提交的内容。 |
| 9 | 无模型、无输入、不可执行时提交限制 | 调整 | Run 执行期间，草稿有内容时可排队；草稿为空且 Run 可取消时，停止按钮替换发送按钮。 |
| 10 | 自动审批失败直接拒绝 | 调整 | 失败、超时、不可用、证据超限或未知风险转人工决定，不自动批准。 |
| 11 | 自动审批明确风险拒绝 | 保留 | 返回原因，模型不能自行重复或绕过。 |
| 12 | 相同审批永久按旧拒绝去重 | 调整 | 指纹包含用户证据；新明确指令可重新审查，普通模型重复仍去重。 |
| 13 | 审批与 Run、Item、准备内容的匹配 | 保留 | 避免把另一操作的授权用于当前副作用。 |
| 14 | 完全访问模式确认及 Run 模式固定 | 保留 | 只有用户能选择模式；模型参数不能升级权限。 |

## Plan 与协作

| 编号 | 检查或门控 | 决策 | 当前行为与依据 |
|---|---|---|---|
| 15 | Plan 控制工具必须单独调用 | 移除 | 混合批次保留原 Worker，等待后顺序继续，不丢弃或重放剩余调用。 |
| 16 | `wait_agents` 必须单独调用 | 移除 | 与混合批次使用相同所有者规则。 |
| 17 | 提问前必须结束自有 Shell | 移除 | 活动 Shell 下原 Worker 等待回答，进程所有者不退出。 |
| 18 | Plan 文本答复必须先提交计划 | 调整 | 可直接说明结论或阻塞；可审阅计划仍必须实际保存。 |
| 19 | 提交计划时子任务尚在执行就报错 | 调整 | 等待必要子任务；可选任务取消后等待资源清理，不等待其完成原任务。 |
| 20 | 忙碌 Agent 不允许 `followup_task` | 调整 | 忙碌时送达消息，空闲时才创建新 Run；操作保持幂等。 |
| 21 | 接收方累计 16 条消息后永久拒绝 | 调整 | 历史持久保留；最早未读消息分组投递，已接受模型请求建立回执，预览或失败不消费。 |
| 22 | 未确认副作用阻断消息和停止操作 | 移除 | 协调和停止不需要解除原副作用事实。 |
| 23 | 未确认副作用阻断只读探索 | 调整 | 可启动或续派 explorer；执行型新 Run 仍受屏障限制。 |
| 24 | Plan 工具只能用于 Plan Run | 调整 | 澄清在普通执行和 Plan 都可用；计划写入仅限 Plan。 |
| 25 | 问题、答案、请求与 Session 所有权校验 | 保留 | 防止迟到响应或跨会话答案覆盖当前任务。 |
| 26 | 计划 ID、版本、确认状态、外部修改校验 | 保留 | 计划是用户审批的具体版本，不能静默覆盖。 |
| 27 | Plan 确认后才能实施 | 保留 | 用户显式选择 Plan 的核心约束；权限批准不等于计划确认。 |
| 28 | 子任务角色、父子归属与单层委派 | 调整 | explorer 可用可信内置只读能力，排除扩权和直接提问；不启动 MCP，不提供 Shell 或子委派。 |
| 29 | 每父 Run 8 个执行中子任务、16 个子 Session | 保留 | 限额只属于该父任务，不占用其他 Run 的执行名额。 |
| 30 | 子任务完成与最终答复的依赖检查 | 调整 | 必要依赖等待结果；可选子任务收尾取消并等待资源静止；迟到结果仍事务复核。 |

## 执行、恢复与资源

| 编号 | 检查或门控 | 决策 | 当前行为与依据 |
|---|---|---|---|
| 31 | 活动 Shell 持续占有副作用门 | 移除 | 仅提交与启动窗口互斥；命令运行时其他调用可继续。 |
| 32 | 所有文件变更因已有 Intent 一概阻断 | 调整 | 可信、已知目标按实际冲突路径判断，提交窗口内复核。 |
| 33 | Workspace refresh 清除所有来源屏障 | 保留限制 | 只恢复可核验的 Workspace Intent；不能证明 Shell 或外部结果。 |
| 34 | 未确认副作用下创建新执行型子任务 | 保留限制 | 在创建事务内检查，防止通过子 Run 绕过屏障或遇到状态竞态。 |
| 35 | 未确认副作用下发送新的非空 Shell 输入 | 保留限制 | Shell ID 不证明文件或外部影响隔离；空输入和 Ctrl-C 可用。 |
| 36 | 不确定 Shell、MCP、外部操作自动重放 | 保留禁止 | 不能把未知结果推定成失败后重试。 |
| 37 | Run 结束仍等待或清理活动进程 | 保留 | 进程必须有所有者；不引入跨 Run 后台服务或孤儿进程。 |
| 38 | 清理前 `has_running` 一律判定 Run 中断 | 调整 | 清理返回实际停止事实，命令自然退出不因旧状态被误判。 |
| 39 | 最终提交校验取消、待消费输入和协作变化 | 保留 | 同一 SQLite 事务决定真实终态，迟到输入不能被成功覆盖。 |
| 40 | 单 Session FIFO | 保留 | 同会话上下文按持久顺序执行；不同 Session 可并行。 |
| 41 | 跨 Session 的全局 Run 或 Worker 限额 | 保持移除 | 不设置全局执行名额或审批等待占位。 |
| 42 | 跨 Run 的共享 Workspace 副作用门 | 保持移除 | 不排队跨 Run 操作；靠原有版本、权限和所有权检查。 |
| 43 | 只读并行必须满足 `parallel_safe` | 调整 | 连续 `parallel_safe` 只读片段可并行，片段之间保留模型声明顺序。 |
| 44 | 超时、取消、进程组清理、资源静止检查 | 保留 | 防止泄漏和迟到结果覆盖终态；人工等待暂停有效执行计时。 |
| 45 | 参数、结果 Schema、Durable Intent、事务 Outbox | 保留 | 防止错误数据入库并保留崩溃恢复事实，不增加重复执行流程。 |
| 46 | Loop 无进展、重复错误和上下文预算 | 保留 | 避免无限循环；新的有效结果和用户证据仍可继续推进。 |

## 文件、Git 与扩展

| 编号 | 检查或门控 | 决策 | 当前行为与依据 |
|---|---|---|---|
| 47 | 首次 Repository generation 阻塞模型执行 | 移除 | 由已有 watcher 所有者构建；Run 使用当时可用 Snapshot 或文件、搜索工具。 |
| 48 | 不完整或未经验证的 generation 发布 | 保留禁止 | 索引是完整、不可变、经身份与内容核验的事实；watcher 事件仅使其失效。 |
| 49 | `read_tool_output` 只允许终态输出 | 调整 | 支持当前 Run 活动 Shell 的累计快照，不消费增量游标。 |
| 50 | 输出 ID 歧义、跨 Session 或跨 Run 活动输出读取 | 保留限制 | 避免取错结果或跨越资源所有权；同 Session 历史终态仍可读取。 |
| 51 | 任意活动 Run 阻止 Skill 清理 | 调整 | 新快照只等待实际使用租约，冻结元数据支持重启；删除禁止新租约，旧快照仍保守保护。 |
| 52 | Skill、Plugin、MCP provenance 与固定快照 | 保留 | 不能在 Run 中静默切换代码来源或权限；Skill 清理仍核验目录身份。 |
| 53 | 活动 Run 禁止 Git stage、commit、fetch、push | 移除 | 保留 Git 原有锁、版本和操作幂等，不设置统一 Session busy 门控。 |
| 54 | 活动 Run 禁止改动工作树结构的 Git 操作 | 保留 | switch、create branch、merge、rebase、pull 会改变执行基线，仍需生命周期互斥。 |
| 55 | 文件 Base Hash、fd 身份、排他创建与最终内容验证 | 保留 | 防止覆盖并发修改、符号链接替换和不完整写入。 |
| 56 | 权限物化、沙盒、扩权与永久拒绝 | 保留 | manual/auto_review 按已建立边界 fail closed；full_access 按用户确认的例外执行。 |
| 57 | 数据目录、凭据、敏感展示和受控路径保护 | 保留 | 遵循权限模式和原有披露边界，不用门控整改开放受保护数据。 |
| 58 | 文件、输出、消息、搜索、MCP 与协议大小预算 | 调整 | 实际资源预算保留；新工具按最近请求换入，搜索满 4 个运行名额后进入有界队列。 |
| 59 | Worktree、Checkpoint、Rewind、删除与恢复身份校验 | 保留 | 这些操作改变或销毁执行基线，需真实生命周期和可恢复操作记录。 |

实现入口：`runtime/tool_runtime.py`、`runtime/tool_execution.py`、`runtime/engine.py`、`runtime/approval.py`、`tools/planning.py`、`persistence/collaboration.py`、`application/repository.py`、`application/git_workflow.py`、`extensions/skill_management.py`，以及 Desktop 的 Composer、ApprovalComposer、ExecutionFeed 和 GitWorkflowControls。

本次按用户明确要求统一整改、提交新分支并创建 PR 后进入测试。验证结果记录在 PR，不把历史验收状态或当前会话授权作为仓库长期门控规则。

## 继续整改后的细分决策

| 编号 | 细分限制 | 当前行为 |
|---|---|---|
| 60 | 普通调用同步等待 Workspace 恢复扫描 | 读取、消息和无关文件不等待；实际冲突、最终提交或需要解除屏障的副作用才恢复。 |
| 61 | 活动 Run 禁止更改模型、推理设置 | 可提前设置下一轮；当前 Run 固定快照。 |
| 62 | 活动 Run 禁止更改权限、Plan 偏好 | 可提前设置下一轮；完全访问仍需用户确认，当前 Run 不变。 |
| 63 | 活动 Run 禁止选择其他项目 | 导航、新会话不受阻；当前 Session 的分支和工作树绑定仍需生命周期检查。 |
| 64 | 存储不可执行就禁止准备引用 | 已加载草稿可操作引用，实际读取和提交仍检查 Runtime 能力。 |
| 65 | 引用准备期间禁止提交 | 保留，防止提交半完成引用。 |
| 66 | 不支持图片的模型禁止提交图片 | 保留，可直接切换下一轮模型。 |
| 67 | 工具激活按名称排序后永久挤出新工具 | 按最新请求换入，16 个定义和 Schema 字节预算保留。 |
| 68 | 4 个搜索运行后立即拒绝新搜索 | 执行器内有界排队，最多 4 个活动搜索，不新增等待线程。 |
| 69 | 重复敏感输入暂停 | 保留内容保护和有界恢复，正常安全调用会重置计数。 |
| 70 | 连续空响应保护 | 保留一次有界协议修复，防止无效模型请求无限消耗。 |
| 71 | 上下文预算不足 | 保留模型真实限制和自动压缩，失败不覆盖原事实。 |
| 72 | 文件与 Patch 上限 | 保留实际内存及协议上限，不要求模型按固定批次拆文件。 |
| 73 | 输出分页上限 | 保留，当前 Run 活动输出仍可读取。 |
| 74 | MCP 工具及结果上限 | 保留协议预算，不重放未知外部结果。 |
| 75 | 引用存储总量 | 保留 512 MiB 上限与现有过期引用回收。 |
| 76 | 权限改动必须再确认才能测试 | 删除历史会话门禁，保留验收覆盖内容。 |
| 77 | 引用改动必须再确认才能测试、检查或构建 | 删除；Shell 分段等待的历史测试授权门禁一并删除。 |
| 78 | 每个 PR 必须所有 Full | 改为按变化边界执行，当前核心整改仍要求 Full。 |
| 79 | 所有 PR 都必须原生、Bundle、DMG | 按路径选择；main push 和相关边界执行完整验证。 |
| 80 | CI 前置失败就跳过全部后续检查 | 独立 Job 并行收集结果，汇总仍要求全部已选检查成功。 |

Schema 17 只增加内部协作投递回执、Skill 租约及必要依赖标记。旧 Schema 16 数据事务升级，旧委派默认必要依赖，旧 Skill 快照保持引用保护。可用 Skill 元数据固定在私有快照中；其内部 JSON 不投影给 Desktop。

未知 Shell/MCP/外部影响、非空 Shell 输入、16 个子 Session 总量、Git 工作树基线变化和 Run 进程所有权保护继续保留。已支持通过 followup 复用子 Session；不自动淘汰委派身份，也不引入跨 Run 常驻服务。
