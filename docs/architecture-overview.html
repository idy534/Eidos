Trust Boundary

Proposal、authorization、policy enforcement 和 durable facts 属于不同边界。

Renderer

Untrusted presentation boundary。只通过 typed IPC 观察和请求状态。

Model output

Untrusted proposal。文本和 ToolCall 必须经过 Runtime validation。

Runtime

Validation、Tool contract、lifecycle、policy 和 reconciliation authority。

Approval

User authorization。Approval 不能改变 Tool 参数或移除 hard deny。

Seatbelt

OS enforcement。默认 Shell attempt 使用 Seatbelt Policy 和有效权限。

SQLite

Durable fact authority。内存对象不能替代已提交的业务事实。
