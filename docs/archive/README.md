# Eidos 历史文档归档

Archive documents are historical evidence.

They may contain:

- old schema numbers;
- old lifecycle budgets;
- superseded APIs;
- old model configuration;
- unimplemented target designs.

They MUST NOT be used as evidence of current Eidos behavior.

当前行为请以生产代码和自动化测试为准。当前文档入口如下：

- [当前架构](../current-architecture.md)
- [当前能力](../current-capabilities.md)
- [当前限制](../current-limitations.md)
- [宏观架构图](../architecture-overview.html)

## 目录

- `phases/` 保存历史 Phase 记录。
- `design-v0.4/` 保存旧 PRD、TDD、Decision 和模型架构设计。
- `references/` 保存外部技术参考资料。

Archive 内部链接保留当时上下文。维护者不应从历史链接反推当前实现。
