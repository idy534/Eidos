# Eidos 历史文档归档

本目录保存历史证据。历史需求、技术设计与阶段记录保持各自的目录和版本。

这些资料可能包含：

- 旧 Schema 编号；
- 旧生命周期预算；
- 已被替代的 API；
- 旧模型配置；
- 当时尚未实现的目标设计。

这些资料不能作为当前 Eidos 行为的依据。

当前行为请以生产代码和自动化测试为准。当前文档入口如下：

- [当前架构](../current/architecture.md)
- [当前能力](../current/capabilities.md)
- [当前限制](../current/limitations.md)
- [交互式架构图](../architecture/overview.html)

## 目录

- [v0.4 历史设计](design-v0.4/README.md) 保存旧 PRD、TDD、Decision 和模型架构设计。
- [v0.4 产品需求](design-v0.4/prd/README.md) 单独组织产品定位、用户流程、功能、安全与验收。
- [v0.4 技术设计](design-v0.4/tdd/README.md) 单独组织架构、状态机、工具、协议和 Desktop 方案。
- [历史 Phase 记录](phases/README.md) 保存 MVP 与阶段基线。
- [历史参考资料](references/README.md) 保存外部技术材料。

新文档的分类入口见 [文档首页](../README.md)。
