# 当前审批与高危范围

本规则用于减少正常 Run 的人工中断。系统分别判断执行权限和操作影响。命令位于沙盒外、目录位于工作区外，或命令使用 Git，都不会单独触发高危人工确认。

## 固定高危范围

系统在申请尚未授权的以下权限时要求人工确认，`auto_review` 不能代替用户决定：

- 操作读取或修改 Eidos 私有数据与保密路径。范围包括状态数据库、聊天、记忆、配置和凭据存储。
- 操作修改 Eidos Runtime、解释器环境、系统 Skill 或受管资源。
- 申请的目录范围覆盖上述受保护路径。

已有当前 Workspace、普通用户 Skill 和已验证运行资源继续使用原有的明确范围例外。普通项目目录 `.eidos` 与 Eidos 私有数据根不是同一类授权。系统仍拒绝链接、特殊文件、不支持的文件对象和版本冲突。

## 普通审批范围

| 操作 | 当前判断 |
| --- | --- |
| Git 暂存、提交、分支、拉取和推送 | 系统按目标、用户授权和实际影响审查，不按 Git 名称判为高危。 |
| 项目 `.git`、`.agents`、`.eidos` 与已验证的 Worktree metadata 写入 | 系统保留默认拒写；明确范围的普通审批或 Run Grant 可以开放。 |
| 普通工作区外文件写入、联网与依赖安装 | 系统使用原有普通审批，继续核对范围与副作用。 |
| 沙盒外 Shell、沙盒不可用时的普通受控文件写入 | 系统继续先审批；`auto_review` 可以根据实际操作批准。执行模式本身不再强制高危人工确认。 |
| 默认 Workspace 文件写入和默认沙盒 Shell | 系统继续使用原有免审批入口。 |

`manual` 继续由用户决定普通审批。`auto_review` 使用当前 Run 的固定模型进行独立审查。模型会区分常规 Git 操作与未授权的未提交内容丢失、历史破坏和覆盖共享历史。模型会审查敏感数据外传、大范围删除、生产变更和长期削弱安全配置等实际影响。模型的明确拒绝会返回工具错误；未知风险、审查失败与重启中断继续回到原有人工入口。普通工具错误和拒绝不自动终止整个 Run。

系统不会为每条默认沙盒 Shell 增加一次模型审查。自动审查仍只覆盖原本需要审批的操作。

## Shell 审查证据

Shell 普通自动审批包含真实执行模式、Eidos 保护路径、Workspace 与普通写入例外。沙盒外进程及其子进程使用当前 macOS 用户的文件和网络权限；请求中的原路径 deny 和网络开关不能继续作为操作系统限制。自动审查不能保证识别全部风险，也不能代替关闭后的 Seatbelt。产品不能承诺沙盒外进程仍受到 Eidos 数据的强制路径保护。

系统还会从命令提到的脚本路径中，读取最多 3 个当前 Workspace 或 active Skill 内的脚本预览。每个预览最多 8 KiB。系统复用 `shlex` 寻找候选路径，并使用现有 `WorkspaceReader` 进行有界、fd-relative 读取。系统不解释 Shell 语法，不执行脚本，也不把这些预览视为完整的 import 或子进程图。链接、范围外和无法读取的脚本会保留缺失标记。预览先经过现有展示脱敏，再进入审批证据；内部文件版本不会注入审查模型。

系统在执行前复检已经预览的脚本。脚本变化会返回 `file_version_conflict`，原命令不会启动。拒绝去重包含脚本预览，因此脚本内容变化后可以重新评估。该复检不能冻结整个进程执行期间的全部依赖。

## 兼容与数据

本次没有新增公开 DTO、数据库表、Schema 版本或依赖。系统沿用原 Approval、Run Grant、Durable Intent、身份与版本核验、取消、结果校验、未知结果和恢复流程。系统不自动重放未知副作用。

新的 Run 会固定新的 metadata 普通审批范围。既有 Run 的基础权限快照保持不变。旧的待处理高危人工审批继续由用户决定原操作；策略放宽不能把旧人工审批静默改成模型批准。命令、Diff、参数和权限指纹仍需匹配。用户确认的 `full_access` 行为保持原样。

回退代码后，新建 Run 会恢复旧策略。维护者应先处理或取消待审批操作，再退出并重启 Eidos。回退不会撤销已经执行的 Git、文件或外部操作，也不会删除已有审批历史。

## 本批验证

2026-10-30 的验证结果：

- 10 个 Runtime 定向文件的主组通过 148 项。范围包括权限分类、项目 metadata、脚本变化、取消、受保护数据、Run 快照、项目多根目录和恢复。
- 新增旧沙盒外审批的批准/拒绝重启恢复与脚本证据变化用例后，审批和 Shell 审查两个文件复跑通过 27 项。本批共覆盖 151 个不同的定向用例。
- 主组中的真实 macOS 用例验证普通 Git 写入获批后可以执行，同时 Eidos 数据仍不可读写。`pnpm test:seatbelt-native` 另通过 15 项，覆盖默认拒绝、明确扩权、数据保护、网络、Skill 与进程组清理。
- Ruff、Deptry、`git diff --check` 和 `pnpm audit:python` 通过。审计覆盖主 Python、隔离文档 Python 和 Runtime Node；审计均未报告已知漏洞。

执行者没有运行 Full Suite、真实 Provider、Desktop 交互或打包验证。模拟审查结果证明 Runtime 分流与副作用顺序，不证明真实模型会批准每条命令，也不证明实际人工弹窗数量已经降到零。先前发现的文档 Skill 复合命令绑定问题不在本批修改中。
