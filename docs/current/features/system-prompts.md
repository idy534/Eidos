# 系统提示词与上下文

Eidos 使用 macOS 桌面通用助手身份。系统支持聊天、研究、文件和编码任务。工作区与工具提供资源，用户请求确定目标。生产规则使用英文，主要文本位于 `model/prompts.py`，组装入口是 `InstructionResolver.resolve` 与 `ContextBuilder`。

## 内容与来源

| 区域 | 当前职责 | 来源 |
| --- | --- | --- |
| 系统提示词 | 系统提供身份、指令顺序、安全与权限原则、任务流程、工具和记忆的使用规则。Runtime 提供实际工作模式和权限状态。 | `model/prompts.py`、`model/instructions.py` |
| 记忆 | 记忆模块提供项目情况、AGENTS.md 与路径约束、全局自定义要求、用户偏好和允许读取的长期记忆索引。 | `memory/context.py` 与各来源的持久快照 |
| 技能 | 系统提供可用名称、描述、加载入口和本轮已加载的说明。 | 冻结的 Skill Catalog、所选 Skill 快照 |
| 工具 | 系统直接提供当前可用工具的原生定义。 | `tools/`、已启用的扩展 |
| 会话与执行记录 | 系统保留真实用户输入、助手回复、工具调用和结果。 | SQLite 历史、输入引用与请求快照 |

系统另行提供运行环境、任务状态、来源说明和历史摘要。这些内容带有来源标记，不会保存成新的人类 Session 消息。用户原文及其附件保持关联，系统不会为翻译、渠道来源或自动任务来源改写原文。

## 独立记忆模块

`MemoryContext` 统一投影记忆内容。每段内容保留 `sectionId`、`source`、`memorySource` 和 `scope`。项目规则继续来自规则解析快照，个性化要求继续来自 Run 的设置快照，长期记忆继续来自现有 Memory 服务。仓库概览按项目记忆分类。系统没有把这些来源迁入同一张表，也没有新增存储权威。

`InstructionLayer` 保留已有的持久化形状。低层指导通过 `context_layers` 取得，系统核心通过 `system_text` 取得。项目规则、个性化要求、长期记忆和 Skill 说明不会合入 `system_text`。上下文统计分别返回 `memory` 和 `skills`，面板以黄色显示记忆。

这些分类表示内容来源，不提高指令权限。当前用户要求优先于项目规则，项目规则优先于所选 Skill，所选 Skill 优先于全局个性化要求，长期记忆属于历史资料。所有内容都不能授予执行权限。路径规则仍按原有项目范围解析，当前事实仍需要按任务核验。

长期记忆的读取、自动学习、全局/项目范围和子 Agent 隔离保持原有规则。关闭长期记忆读取不会删除或关闭用户明确设置的项目规则和个性化要求。记忆索引保留私有撤销版本与记录引用；模型适配器只发送正文，不发送这些私有字段。关闭、遗忘、请求准入、重试与迟到响应继续经过原有检查。

## 模型适配与恢复

Provider 没有通用的 memory 角色。逻辑 `context` Item 在 Pydantic AI 路径中使用兼容的 `UserPromptPart`，在 Responses 路径中使用 user 消息。系统不会把背景内容提升为 `SystemPromptPart` 或 developer 消息。这个传输角色不代表系统新增了人类 Session 消息，也不改变来源分类。

适配器沿用历史响应、推理与图片的原有兼容处理。正常工具回放继续保留原生调用与结果关系。恢复投影保留当前用户目标、项目和 Skill 指导、记忆来源与范围、隐私撤销记录和连续性信息。系统不会为了恢复上下文自动重放副作用。

## 工具与 Skill

当前 Run 中已配置、可用且符合角色范围的工具从首轮直接提供。项目与无项目主 Run 使用相同原则。内置 automation 与已启用 MCP 工具也直接提供。系统不注册 `tool_search`，也不要求搜索后激活工具。参数校验、审批、Sandbox、Durable Intent、结果核验与未知结果记录继续生效。

旧激活记录和快照字段保留读取兼容。历史 Step 中原本不可用的调用不会因新版直接展示而自动重放。未知、禁用和未授权工具不会进入目录。

Skill 目录使用 `available_skills` 区域。每项包含唯一名称、description 和 `skill_read` 加载入口。名称对应 `qualifiedId`。模型使用 Skill 时读取主说明，再按需要通过 `skill_read_resource` 读取相对文本资源。目录不注入全部正文或文件树。同一 Turn 的目录与所选内容继续使用冻结快照。

Skill 的加载、资源 Lease 和身份检查继续生效。工具直接可用不会开放所有 Skill 文件，也不会授予写权限。

## 流程、环境与验证

简单问候、闲聊和已有信息足以直接完成的请求可以直接回复。其他任务遵循英文三步流程：识别意图，按需要规划，然后执行与验证。系统不要求模型公开内部推理，也不要求用户给自然输入添加特殊标签。

项目和无项目 Run 都提供实际工作目录、附加目录、平台、宿主 Shell、当地日期与时区。精确时间任务仍应取得新鲜时间。已持久化请求的重试继续复用原快照。

本轮没有增加依赖或数据库迁移。公开上下文统计协议增加 `memory`、`skills` 两个分类，旧分类仍然有效。历史请求不会被改写。回退时应还原本轮源码与生成契约并重新载入 Runtime，维护者不应删除用户记忆或历史快照。验证范围与模型效果限制见[当前限制](../limitations.md#独立记忆上下文2026-11-01)。
